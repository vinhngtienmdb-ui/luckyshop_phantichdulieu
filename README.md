# Lucky Shop Analytics

Financial analytics dashboard for Lucky Shop, featuring daily lixi projections and ROI calculations.

## Built With
- React 19 + Vite
- Tailwind CSS 4
- Firebase (Firestore & Auth)
- Lucide React Icons
- Motion (Framer Motion)

## Synchronization with GitHub

This project is linked to [vinhngtienmdb-ui/lucky-shop-dashboard](https://github.com/vinhngtienmdb-ui/lucky-shop-dashboard).

### How to sync changes from AI Studio to GitHub:
1. Click the **Gear icon (Settings)** in the top-right corner.
2. Select **Export to GitHub**.
3. Choose your repository and branch.
4. Click **Export**. This will push your current local changes to GitHub.

### How to pull changes from GitHub to local:
If you make changes on GitHub (e.g., via a PR) and want to bring them back here, you can use the **Import from GitHub** option in the same Settings menu.
